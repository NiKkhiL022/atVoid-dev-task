🎨 Naming Conventions - BEM Methodology

I implemented the BEM (Block Element Modifier) naming convention throughout the project for clarity and scalability.

BEM Structure

Block:

.hero

Element (child of block):

.hero__title
.hero__product-img
.hero__addcart

Modifier (variation of block/element):

.pack-option--selected
.nav__link--active
.flavour-card__image--blue

Key Benefits

  • Modularity: Each block (nav, hero, pack-option, etc.) is self-contained with its own styles
  • Clarity: Class names describe purpose and hierarchy
  • Maintainability: Easy to locate and modify specific elements
  • Scalability: Simple to add new features without conflicts

Mobile-First Approach

I used a mobile-first methodology with progressive enhancement:

  • Base styles designed for mobile devices
  • Media queries add complexity for larger screens
  • Flexbox and CSS Grid for flexible layouts
  • Touch-friendly button sizes (min 44px tap targets)

💻 Technical Implementation

HTML Structure

  • DOCTYPE HTML5: Modern standard compliance
  • Meta Tags: Proper viewport, charset, and SEO metadata
  • Semantic Elements: header, nav, main, section for structure
  • Accessibility: ARIA labels, alt text, proper heading hierarchy

CSS Architecture

  • BEM Methodology: Consistent naming across all components
  • Custom Fonts: Multiple Helvetica variants with fallbacks
  • CSS Variables: For maintainable color schemes (after DRY refactor)
  • Flexbox & Grid: Modern layout techniques
  • Animations: Smooth transitions and keyframe animations
  • Media Queries: Progressive enhancement for responsiveness

JavaScript Features

  • Mobile Menu Toggle: Hamburger menu with backdrop and smooth transitions
  • Quantity Counter: Increment/decrement with min/max limits
  • Pack Selection: Visual feedback for selected product variant
  • Add to Cart: Notification system with animation
  • Smooth Scrolling: Enhanced navigation experience
  • Keyboard Navigation: ESC key to close modals
  • Intersection Observer: Scroll-triggered animations
